# Symbolic Collapse Model (SCM)

*A quick primer for new visitors*

---

## What is SCM?

SCM is a quantitative **pressure gauge** for information systems. It tells you **how close a network, organization, or conversation is to symbolic overload and collapse** by collapsing five core variables (plus optional modifiers) into a single score **𝒞**.

---

## Variables & Modifiers

```
𝒞 = f(T, E, S, I, P, M₁…Mₙ)
```

| Symbol | Name                  | Meaning                                                                         | Typical Range       |
| ------ | --------------------- | ------------------------------------------------------------------------------- | ------------------- |
| **T**  | Transmission fidelity | Are messages arriving intact?                                                   | 0 – 1 (1 = perfect) |
| **E**  | Epistemic coherence   | Do the pieces fit together logically?                                           | 0 – 1               |
| **S**  | Signal intensity      | How loud / fast / novel is the stream?                                          | 0 – ∞               |
| **I**  | Information inertia   | How resistant are old symbols to change?                                        | 0 – ∞               |
| **P**  | Polarization          | How mutually exclusive are symbol clusters?                                     | 0 – 1               |
| **Mₓ** | Modifiers             | Context‑specific dampers/boosters (e.g., Nostalgia Weight, Emotional Resonance) | −1 … +1 each        |

Higher 𝒞 ⇒ higher collapse risk.

---

## What you can do with SCM **today**

* **Rust core library** – embed real‑time 𝒞 scoring in any app.
* **Web simulator** – move sliders, watch stability fracture or heal.
* **CLI tools** – batch‑score text, social feeds, or CSV data.

## What I hope SCM enables **tomorrow**

* **Browser filters** that hide or reorder high‑𝒞 content before it overwhelms us.
* **AI safety throttles** that detect when a model’s output would raise collapse risk.
* **Civic dashboards** mapping symbolic fracture zones across cities or institutions.
* **Early‑warning monitors** for organizations drowning in conflicting signals.

If you see another application, open an issue – let’s experiment.
